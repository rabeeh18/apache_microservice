Notes / How To Use

This GUI connects to the local Embedding Service and Apache Solr instance.

  • Search: Type a query and hit Search. The text is embedded and sent to Solr for KNN similarity search.
  • Result Count: Choose how many results to retrieve.
  • Preview: Click "Show Preview" on any result to see the associated text.
  • Combined Score: Shows the arithmetic mean of the similarity scores for the selected result set.
